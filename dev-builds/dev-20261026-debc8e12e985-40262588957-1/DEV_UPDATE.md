### 新增 · 自动填写 PDF 文档属性

变化：模板把论文标题、作者和关键词写入 PDF 文档属性；英文论文先取英文字段，未填时取对应中文字段。手工设置的属性优先。

适用范围：所有填写了论文信息的论文。

旧稿处理：可按需调整。继续使用已有的论文信息配置即可。要单独设置 PDF 属性，可在导言区按示例指定字段，手工设置优先，留空也保留。

使用示例：

```latex
\hypersetup{pdftitle={自定义 PDF 标题}, pdfauthor={}}
```

### 调整 · URL 字符间距默认不拉伸

变化：正文和参考文献中的 URL 不再随两端对齐拉大字符间距，断行仍用宏包已有断点，链接目标不变。在导言区设置的字符伸缩量也会用于参考文献。

适用范围：正文或参考文献中含 URL 的论文。

旧稿处理：无需修改现有写法。

### 新增 · 新增公式符号说明环境

变化：eqdenote 把引导词、符号、破折号和说明分列对齐，长说明在本列内折行，页满时在条目之间分页，说明不占表号。引导词默认“式中”，英文论文为 where，可用可选参数替换。

适用范围：需要在公式后逐项解释符号的中英文论文。

旧稿处理：可按需调整。原有手写说明仍可使用。精简 TeX 安装需先安装 tabularray 宏包；新写法见示例。

使用示例：

```latex

  \item $m$ & 质量，kg。
```
