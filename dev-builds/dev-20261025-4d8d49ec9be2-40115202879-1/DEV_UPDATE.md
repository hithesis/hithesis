本次开发版补回了此前仅进入 dev 的三校区封面与中期报告修正，新增数字年月日封面日期、英文内封长字段自动折行、中英文双语题注统一入口，并修复封面 PDF 跳转与书签显示。关键词续行默认改为顶格对齐，是唯一会影响旧论文外观的默认变化，可在 hitsetup 中用 keywords-hanging=true 恢复旧版悬挂对齐。其余旧命令和写法继续有效。

## 关键词续行默认顶格

摘要关键词超过一行时，续行现在从正文左边界开始，不再悬挂对齐到第一个关键词。实际对照中，末尾几个关键词的起始位置整体左移。

适用情况：所有使用默认设置、且关键词超过一行的论文，摘要关键词区域外观会变化。

旧论文怎么改：想保持旧版悬挂对齐，在现有的 hitsetup 设置中加入 keywords-hanging=true；不介意新对齐的论文无需改动。

```latex
\hitsetup{keywords-hanging=true}
```

排版前后对照图见同版 PDF 附件。

## 封面日期支持数字年月日

现有日期字段可以直接写数字格式：cdate 写年月会显示为对应的中文年月，edate 写年月日会显示为英文月份、日和年份。手写的中文、英文日期以及元信息原值继续保留原样。

适用情况：使用封面日期字段的论文；不改成数字写法的不受影响。

旧论文怎么改：无需强制修改。想用数字写法时，按现有设置方式填写 cdate 和 edate 即可，具体写法见示例。

```latex
\hitsetup{
  cdate={2026-06},
  edate={2026-06-15}
}
```

## 英文内封长字段自动折行

英文内封中的学院、专业、导师等字段过长时会按可用列宽自动折行，并利用标题区空白容纳增加的行高。普通短字段保留原来的排法，已有的手动分行写法也能继续用。

适用情况：英文内封中存在超长字段的论文；短字段封面不受影响。

旧论文怎么改：无需修改。原先为塞进封面手动断开的行可以保留，也可以去掉让模板自动折行。

排版前后对照图见同版 PDF 附件。

## 中英文图表题注统一入口

图、表和 longtable 可以把中英文题注写在同一条 caption 命令里，支持短标题和星号不编号形式；两种语言共用一个编号，英文题注不会重复进入图表清单。旧的 bicaption 和 longbionenumcaption 继续支持。

适用情况：需要中英双语题注的图、表和长表；只用单语题注的论文不受影响。

旧论文怎么改：无需整篇替换。可继续用旧命令；想改用统一入口时，按示例写主语言题注并在末尾方括号中写副语言题注。

```latex
\caption[清单短标题]{中文题注}[English caption]
\label{fig:example}
```

## 深圳参考文献不再强制大写作者名

取消深圳参考文献样式中作者姓名被硬编码为全大写的处理，作者名按原始大小写显示。

适用情况：使用深圳参考文献样式的论文，参考文献中的作者名大小写会变化。

旧论文怎么改：无需修改论文内容。

## 封面 PDF 跳转与书签修复

适用情况：所有生成 PDF 的论文，主要影响封面和目录中的跳转与书签显示。

旧论文怎么改：无需修改论文内容。
