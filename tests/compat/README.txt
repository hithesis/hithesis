# 旧版面兼容回归的变体配置
#
# 这一轨钉死在 v3.1e，不随发版漂移。测的是「老文档在新模板的兼容层（v2-layout）
# 下，排出来还是不是老样子」。旧版面要长期保留，所以这一轨是常设的。
#
# 形状是同一份内容编两遍：
#   参照侧  v3.1e 的示例内容 + v3.1e 的类           OPTIONS / CLS
#   当前侧  v3.1e 的示例内容 + 当前的类 + v2-layout  OPTIONS_NEW / CLS_NEW
#
# 不能各编各的树：两版的示例内容本身就不同，逐页比出来全是内容差异，没有意义。
#
# 字段：
#   BASE         示例目录（相对 v3.1e 的树根）
#   ENTRY        入口 .tex
#   OPTIONS/CLS          参照侧的 \documentclass 选项与类名
#   OPTIONS_NEW/CLS_NEW  当前侧的；不写就沿用参照侧那份
