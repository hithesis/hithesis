# 数学后端的验收标准

数学内部排版以 LaTeX 为准，学校规范决定公式居中、编号、编号位置和版面间距。
Word 数学渲染的字形、数学轴或坐标不作为 LaTeX 数学内部排版的唯一基准。

## 行内公式

- 保留 `amsmath` / `unicode-math` 算好的数学基线、数学轴、上下标和符号关系。
- 在非固定行距中，公式按实际 LaTeX 盒子的高度和深度参与行盒布局。
- 小公式能装入正常行盒时，不产生无缘由的额外行高。这个条件须先检查实际高深，
  不能要求所有数学内容都和普通文字同位。
- 大分数、矩阵等确实超出正常行盒时，允许按段落行距规则撑行，避免与上下行碰撞。
- 数学字体的全局 Win/hhea/typo 度量不等于单个数学对象的实际盒尺寸。
  不能按字体名统一回退或固定所有公式行高；普通文本 run 的字体度量仍按其文本语义处理。

## 行间公式

使用 LaTeX 数学环境及模板配置排公式上下间距和编号。分式、根号、矩阵、上下标等
内部几何保留数学后端结果，不逐字复刻 Word 公式。固定行距与非固定行距应分别验证，
不能用固定行距探针掩盖非固定行距中的异常撑行。

## 当前回归

```sh
texlua tests/feature/run.lua -j 2 -e xelatex,lualatex --keep \
  inline-math-linebox inline-math-size
```

- `inline-math-linebox`：先确认 `$T$` 的实际高深装得进普通撑杆，再检查它不异常撑高间距。
- `inline-math-size`：分数、三行矩阵和显式装盒分数，按测得的公式/文字高深检查前后行不碰撞。
  不固定大公式的具体间距，也不把普通 `T` 和 `$T$` 的条件推广到所有公式。

这两项是 LaTeX 数学与段落衔接的回归，不是 Word 数学 oracle。图盒边界余量、目录与名单
接排另行验收；数学标准的调整不取消那些已确认问题的修复要求。

## 整本 Word 参考中 4.4 节前的累计差

博士/本科范例的两条显示公式及三个说明符号均为旧式 `Equation.3` 对象，带有预览尺寸和
手工下移量。它们不是 LaTeX 对应数学盒的同尺寸输入；后面的标题位置不能直接用于校准标题前距。
可见内容也有区别：Word 第一式及第三条说明使用 φ，当前 LaTeX 样稿分别使用 α 和 C₂；
第二式的分式组合形式也不同。原稿保留，这些位置不作为数学内部排版的同文 oracle。

实际 Word 的这些段落段前/段后均为 0。相对公式引入段，4.4 标题的累计差为约
18.6/17.6bp（Word−LaTeX）；符号说明后的省略号到标题本身，两端步进均为 32.2bp。
只把说明符号替换为普通小内容后，累计差分别为 12.0/11.0bp；进一步替换显示公式并统一

这些是保留原输入后的独立控制，不刷新正式 fixture，也不据此调整 LaTeX 数学字体、数学轴或固定补偿。
