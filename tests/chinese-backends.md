# 中文后端测试

模板采用上游提供的中文支持：LuaLaTeX 使用 luatexja，XeLaTeX 使用 xeCJK 及其
ctex 辅助包，pdfLaTeX 使用 ctexbook 初始化 CJK。Unicode 引擎的底类仍为 book，
封面、标题和正文版式由模板与 docxlike 设置。

## 运行

先运行 `make cls`，再指定一个尚不存在的工作目录：

```sh
python3 tests/run-chinese-backends.py --work /tmp/hithesis-backends
```

脚本冻结当前生成物与示例，检查三个引擎实际加载的后端文件。四项小样覆盖 UTF-8
还原与分组、中文标点、字体切换、分节、正文提取、书签，以及 pdfLaTeX 缺少中易字体时
的文鼎回退。只运行小样可加 `--small-only`。

完整矩阵每个引擎八项，共 24 项：哈尔滨博士和本科论文、深圳硕士英文论文、威海硕士
开题报告，以及深圳硕士中文和博士英文的开题、中期报告。结果写入工作目录的
`results.json`，各项编译日志保留在相应子目录。

加 `--extended` 可扩为 39 项，补充博士后、专业学位博士、威海本科论文，以及深圳本科
中文开题和英文中期报告，适合检查跨部件词条和封面设置。

升级后端时，除检查编译结果外，还应与已验证版本比较页数、断行、字符位置及书签。
本测试不要求三个引擎的输出相同，也不以成功编译代替版式检查。
