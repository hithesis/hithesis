# 生成物的分发清单，Makefile 与 build.lua 都读这一份。

# 格式：一行一个文件名。
#   名字           拷进 examples/demo/
#   名字 -> 子目录  拷进 examples/demo/<子目录>/

#
# 空行与 # 开头的行忽略。
#

# 报出来：install 守卫新生成一个文件，这里既没列出也没写进排除表，就是漏了。
#
# assets/ 下的 PDF 不是 docstrip 的产物，是提交进仓库的二进制。它们由
# hit-eps.dtx 解出的 EPS 用 epstopdf 转来，见下面排除表里的说明。
