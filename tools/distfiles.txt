# 生成物的分发清单，Makefile 与 build.lua 都读这一份。
#
# 格式：一行一个文件名。
#   名字           拷进 examples/demo/
#   名字 -> 子目录  拷进 examples/demo/<子目录>/
#   !名字  理由     生成了但不分发，写明为什么
#
# 空行与 # 开头的行忽略。
#
# 权威的产物清单是 src/hithesis.dtx 的 install 守卫里那批 \file{}。
# 这份说的是「其中哪些要拷进示例目录」。两边对不上由 scripts/products.py
# 报出来：install 守卫新生成一个文件，这里既没列出也没写进排除表，就是漏了。
#
# assets/ 下的 PDF 不是 docstrip 的产物，是提交进仓库的二进制。它们由
# hit-eps.dtx 解出的 EPS 用 epstopdf 转来，见下面排除表里的说明。

hit-thesis.cls
hit-report.cls
hithesis.cls
hithesisbook.cls
hithesisart.cls
hithesisartplus.cls
hithesis.sty
hithesis.bst
hithesis.ist

# 模板资源：封面上的校徽、题名、落款，装进 tex/latex/hithesis/，见 build.lua
assets/hit-logo.pdf
assets/hit-bachelor-report-bottommark.pdf

# 示例与手册的内容，不是模板资源，只随示例目录发，不进 tex/latex/hithesis/。
# 示例正文按 figures/golfer 引用插图，得放进子目录；二维码按 zfb 引用，放根下。
@assets/zfb.pdf
@assets/golfer.pdf -> figures

# 不分发的两个
!dtx-style.sty  只在排手册时用，示例文档碰不到它
!hithesis.ins   解压驱动，示例目录里用不到；它跟着源码包发

# 四份 EPS 降为中间产物。XeLaTeX 自己不认 EPS，是把文件丢给 xdvipdfmx 调
# ghostscript 转，也就是说每个用户都得装 gs 才编得出封面。改成事先转好 PDF
# 随包发，gs 只有维护者跑 make eps2pdf 时要。EPS 留在 hit-eps.dtx 里当可读、
# 可 diff 的源，改图动那边，再跑一次 eps2pdf。
!hit-logo.eps                  转成 assets/hit-logo.pdf 分发
!zfb.eps                      转成 assets/zfb.pdf 分发
!hit-bachelor-report-bottommark.eps  转成 assets/hit-bachelor-report-bottommark.pdf 分发
!golfer.eps                   转成 assets/golfer.pdf 分发
